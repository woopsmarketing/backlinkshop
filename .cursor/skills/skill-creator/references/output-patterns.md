# Output Patterns

Use these patterns when skills need to produce consistent, high-quality output.

## Template Pattern

**Strict requirements:**

```markdown
# [Title]

## Executive summary
[One paragraph]

## Key findings
- Finding 1
- Finding 2

## Recommendations
1. Actionable recommendation
2. Actionable recommendation
```

**Flexible guidance:**

```markdown
# [Title]

## Executive summary
[Overview]

## Key findings
[Adapt based on what you discover]

## Recommendations
[Tailor to context]
```

## Examples Pattern

Provide input/output pairs when style matters.

```markdown
Input: "Added user authentication with JWT"
Output:
    feat(auth): implement JWT-based authentication

    - add login endpoint
    - validate tokens
```
