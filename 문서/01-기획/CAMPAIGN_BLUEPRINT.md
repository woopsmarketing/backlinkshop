## 0. 전체 전략 — 포지셔닝 재정의

### 0-1. 핵심 메시지

**"구글 상위노출의 숨은 공식 = 백링크 + 내부 SEO. 백링크샵은 두 개를 동시에 해결하는 유일한 원스톱."**

경쟁사들은 백링크만 팔거나(품질 의심), SEO 컨설팅만 한다(느리고 비쌈). 백링크샵은 **"진단 → 백링크 → 내부 SEO → 리포트"** 를 한 플랫폼에서 처리하는 점을 무기화합니다.

### 0-2. 심리 트리거 8가지 (광고 카피 설계 원칙)

| 트리거            | 메시지 예시                        | 어디 쓰는가           |
| ----------------- | ---------------------------------- | --------------------- |
| **손실 회피**     | "경쟁사는 이미 1페이지"            | 헤드라인, 설명 앞부분 |
| **구체성**        | "10분", "50개 항목", "20만 크레딧" | 모든 카피             |
| **희소성·즉시성** | "지금 무료" "오늘만"               | 보조 CTA              |
| **권위**          | "화이트햇 전용" "3년 운영"         | 설명, 사이트링크      |
| **호혜성**        | "20만원 상당 진단을 무료로"        | 헤드라인, 설명        |
| **호기심 격차**   | "낮은 진짜 이유" "숨은 공식"       | 헤드라인              |
| **사회적 증거**   | 실제 검증 가능한 수치만            | 설명 보조             |
| **쉬운 실행**     | "카드 등록 없이" "10초 가입"       | 설명 끝               |

### 0-3. 금지어 체크

**키워드에 절대 넣지 말 것** (정책 위반 소지):

- `블랙키워드` `블랙해트` `black hat`
- `해킹` `조작` `어뷰징`
- `순위 조작` `검색 조작`
- `구글 속이기`
- `자동 프로그램` `봇`
- 경쟁사 상표명 직접 매칭

**광고 제목에서 주의 (일부만 쓸 것)**:

- `블랙키워드 상위노출` — **사용자가 실제로 검색하는 단어라 가치는 있지만**, Google 심사에서 **`기만적 콘텐츠 정책`** 으로 거부될 수 있음
- **대안 전략**: "블랙키워드 잡기" 같이 **방어 문구로 포지셔닝** ("블랙키워드에서 안전하게" 등)

## 8-B. 기존 광고그룹 처리 전략 (중요)

> 상황: 이미 작동 중인 광고그룹 1개가 있음. 전환 14회, 학습 중 81% 상태. 삭제하면 학습 데이터 손실.

### 원칙

1. **삭제 금지** — 학습 데이터 보존
2. **일시중지** — 새 그룹 안정화 확인 후 결정
3. **"백링크" 키워드 이전** — 그룹 A 에서 계속 활용

### 처리 순서

#### Step 1 — 기존 그룹에서 성과 확인 (5분)

- [ ] 캠페인 → 기존 광고그룹 선택 → **키워드** 탭
- [ ] 지난 30일 기준 클릭·전환 정렬
- [ ] **상위 3~5개 고성과 키워드 이름 메모**
- [ ] **하위 키워드** (품질점수 낮음 · 노출 0) 이름 메모

#### Step 2 — 고성과 키워드를 그룹 A/B 에 반영 (10분)

고객님이 말씀하신 **"백링크"** 는 이미 그룹 A 의 키워드 복붙 블록에 포함돼 있어요 (구문, max CPC 5,500). 그 외에 기존에 효과 있던 키워드가 있다면:

- 백링크 관련 → 그룹 A 키워드 목록에 추가
- 상위노출 관련 → 그룹 B 키워드 목록에 추가
- 해당 키워드 개별 max CPC 는 기존 성과 데이터 기반으로 조정

#### Step 3 — 그룹 A, B 런칭 (섹션 9 체크리스트 참조)

- [ ] 그룹 A 생성 + 활성화
- [ ] 그룹 B 생성 + 활성화

#### Step 4 — 기존 광고그룹 일시중지 (3분)

> ⚠️ **Step 3 완료 직후에만** 실행. 새 그룹이 활성화되지 않은 상태에서 기존 그룹을 멈추면 트래픽 0 위험.

- [ ] 캠페인 → 광고그룹 탭 → 기존 그룹 좌측 상태 토글 클릭
- [ ] **"일시중지"** 선택
- [ ] 저장
- [ ] 1~2분 후 캠페인 요약에서 노출 지표 확인 — 새 그룹 A/B 로 트래픽이 흘러가는지

#### Step 5 — 24시간 관찰

- [ ] 다음날 아침 새 그룹 A, B 의 노출·클릭 확인
- [ ] 최소 노출 100+ 시 정상 작동
- [ ] 노출 0 이면 일시중지 해제 고려 (그룹 A/B 키워드·카피 거부 여부 점검)

### 복구 플랜 (만약 새 그룹이 문제 있으면)

기존 그룹 → 일시중지 → **재개 (Enable)** 로 즉시 복구 가능. 일시중지는 학습 데이터를 유지하므로 **언제든 복귀 가능한 안전장치**입니다.

## 12. 심리 트리거 적용 매핑 (왜 이 카피가 먹히는가)

| 카피                    | 심리 원리       | 기대 효과                    |
| ----------------------- | --------------- | ---------------------------- |
| "구글에서 몇 페이지?"   | 호기심 격차     | 클릭 유발 (궁금증 해소 욕구) |
| "경쟁사는 이미 1페이지" | 손실 회피       | 방치 비용 인식               |
| "20만원 상당 무료"      | 호혜성 + 구체성 | 거절하기 어려움              |
| "카드 등록 불필요"      | 마찰 제거       | 시도 장벽 낮춤               |
| "3년 운영, 화이트햇"    | 권위 + 안전     | 신뢰 구축                    |
| "10분 안에 리포트"      | 즉시성          | 기다림 불안 제거             |
| "50개 항목 정밀"        | 구체성          | 가치 인식                    |
| "블랙키워드 방어"       | 공포 → 해결     | 니즈 증폭                    |

**핵심 원칙**: 모든 카피는 **"구체적 + 즉시 실행 가능 + 낮은 마찰 + 검증 가능"** 4요소 중 최소 2개를 포함해야 합니다. 막연한 최상급(`최고`, `국내 1위`) 금지.

## 13. 금지/주의 사항 총정리

### 13-1. 키워드 금지어 (심사 거부 우려)

- `블랙키워드`, `black hat`, `블랙해트`
- `해킹`, `조작`, `편법`
- `순위 조작`, `검색 조작`
- `자동 프로그램`, `봇`
- 경쟁사 브랜드명 직접 매칭

### 13-2. 광고 카피 주의어

- **절대 금지**: "최고", "국내 1위", "유일한", "최저가" (증빙 없으면 금지)
- **주의**: "블랙키워드" 단어는 10개 중 1~2개 광고에만, 항상 "방어/안전" 프레임으로
- **검증 필수**: "1,247개 기업", "98% 재구매", "패널티 0건" — 실증 자료 없으면 삭제

### 13-3. LP 일관성

- 광고에서 약속한 것(무료 진단, 20만 크레딧, 10분 리포트)은 LP 에서 **첫 스크롤 안** 에 반드시 재확인
- 광고와 LP 문구가 다르면 품질점수 하락

## 15. 전담 마케터 권고

### 지금 당장 (오늘~내일)

1. **광고그룹 A부터** 만들기 (가장 구매 의도 높음)
2. 각 그룹마다 "복붙 → 업로드 → 미리보기 → 활성화" 순서 고정
3. 입찰 전략 **반드시 "클릭수 최대화"** 로 1~2주차 운영
4. **전환 추적 작동 확인 없이 캠페인 활성화 금지** — `sign_up` 발화 테스트 선행

### 첫 주 피해야 할 유혹

- ❌ 전환수 최대화 유지 (데이터 부족으로 노출 억제)
- ❌ 일 예산 급상향 (학습 왜곡)
- ❌ 키워드 20개 초과 투입 (관리 불가)
- ❌ 광고 문구 자주 바꾸기 (최소 7일 관찰 후 변경)

### 첫 달 절대 원칙

- **전환 0 공포에 빠지지 말 것.** 1주차는 "트래픽 모으기 + 검색어 정제"가 목표. 전환은 2주차부터 나타나기 시작함.
- **매일 대시보드만 보지 말 것.** 일요일마다 주간 리포트 작성이 훨씬 효과적.
- **A/B 테스트는 2주차부터.** 초기에는 하나의 가설을 밀고 나감.
