## 1. 메타데이터 & SEO 설정

### page.tsx:10-15

```ts
metadata = {
  title: '무료 SEO 진단 | 백링크샵 - 구글 상위노출 전문',
  description:
    '구글 검색 순위가 낮은 진짜 이유, 10분 안에 무료로 확인하세요. 이메일만 입력하면 경쟁사 비교 분석까지 포함된 정밀 리포트를 보내드립니다.',
  robots: { index: false, follow: false },
}
```

**핵심 포인트:**

- 검색엔진 노출 차단 — **광고 트래픽 전용** LP
- 자연 검색 메타 디스크립션 최적화는 의도적으로 안 함
- `force-static`으로 빌드 타임 정적 생성 → CDN 캐싱으로 LCP 최적화

### 제출 로직 (LPHeroForm.tsx:20-81)

1. 빈 값 검증 (3개 필드 모두 필수)
2. `normalizeEmail()` + `toDomainSlug(url)` 정규화
3. `ref` 쿼리 파라미터 추출 (없으면 `(none)`)
4. **이메일 → sessionStorage 저장** (`LP_EMAIL_STORAGE_KEY`) — `/analyze` 페이지의 텔레그램 CTA EC 추적용
5. **GA4 이벤트 발화:**
   - `sha256Email()` → `trackSetUser(emailHash)` (Enhanced Conversion user_data)
   - `trackLpSubmit({ ref, domain })` (lp_form_submit 이벤트)
6. `POST /api/lp/request` 호출
7. 응답의 `redirectUrl` 또는 `/analyze/{slug}` 폴백 경로로 라우팅
8. 실패 시: 에러 메시지 빨강 알림 박스 표시

**중요:** LP 페이지 자체의 텔레그램 버튼은 `telegram_click` GA 이벤트를 **발화하지 않음**.
→ 광고 전환 측정은 `/analyze/[domain]` 페이지의 텔레그램 CTA에서 **단일 진입점으로 통일**.
