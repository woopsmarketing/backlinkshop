### 해석 1 — "백링크" 과최적화

본문 공백 제외 4,593자 중 "백링크"(3자) × 121회 = 363자. **본문 글자의 7.9%가 문자 그대로 "백링크"라는 단어**입니다.

일반적인 자연스러운 한국어 상업 콘텐츠에서 주 키워드 밀도는 1~2% 수준입니다. 7.9%는 그 4~8배로, Google의 스팸 정책 문서가 기술하는 "키워드 스터핑(keyword stuffing)" 판단 구간에 해당할 수 있습니다.

특히 H2 9개가 **전부** "백링크"를 포함하고, 그 중 5개는 "백링크 + 구글 상위노출 + 검색엔진최적화"를 한 문장에 함께 넣었습니다.

```
H2-1. 95%의 백링크 업체는 저품질 스팸 링크를 판매합니다
H2-2. 10가지 이상 고품질 백링크 유형으로 자연스러운 검색엔진최적화
H2-3. 고품질 백링크로 구글 상위노출에 성공한 실제 검색엔진최적화 사례
H2-4. 구글 상위노출의 첫걸음, 내 도메인과 경쟁사 도메인을 무료로 분석하세요
H2-5. 고품질 백링크와 검색엔진최적화가 필요한 분들께 추천합니다
H2-6. 백링크 작업 전 SEO 진단과 맞춤 검색엔진최적화 전략 제안
H2-7. 구글 상위노출을 위한 맞춤형 SEO 백링크 상품
H2-8. 백링크와 검색엔진최적화(SEO) 자주 묻는 질문
H2-9. 고품질 백링크로 구글 상위노출, 지금 시작하세요
```

9개 H2가 서로 다른 **주제**를 말하는 게 아니라 서로 다른 **키워드 조합**을 말하고 있습니다. 검색엔진에게는 "이 페이지는 무엇에 관한 페이지인가"의 신호가 오히려 흐려집니다.

### 해석 2 — 상업 키워드의 역설적 부재

가장 중요한 발견입니다.

| 키워드             | 본문 출현 | `[내부-Ads]` CPC | `[DDG-KR]` 현재 순위 |
| ------------------ | --------: | ---------------: | -------------------- |
| 백링크 구매        |   **1회** |          9,446원 | **1위** ✅           |
| 백링크 판매        |   **0회** |          9,446원 | **5위** ✅           |
| 백링크 업체        |       2회 |          9,446원 | 순위권 밖            |
| 백링크 가격        |   **0회** |        확인 불가 | 순위권 밖            |
| 백링크 구매대행    |       0회 |         12,989원 | 확인 불가            |
| 백링크 구매사이트  |       0회 |         14,760원 | 확인 불가            |
| 백링크 판매 사이트 |       0회 |         15,350원 | 확인 불가            |

**CPC 9,000~15,000원짜리 최고가 상업 키워드들이 본문에 0~2회밖에 등장하지 않습니다.** 대신 정보성 성격이 강한 "백링크"가 121회 반복됩니다.

역설적으로 `백링크 구매`에서는 이미 1위입니다(`[DDG-KR]`). 이건 홈페이지 콘텐츠가 아니라 **도메인명 `backlinkshop.co.kr` 자체와 title 태그의 힘**으로 보입니다. 즉 **본문 최적화 없이도 1위인 키워드**이며, 여기에 전용 페이지를 붙이면 방어력이 훨씬 올라갑니다.

### 해석 3 — 표기 변형 누락

한국어 검색에서 띄어쓰기 변형은 별개 질의로 집계됩니다. `[내부-Ads]` 데이터에서도 두 변형이 별도 키워드로 관리되고 있습니다.

| 변형 쌍                          | 본문       | `[내부-Ads]` 검색량        |
| -------------------------------- | ---------- | -------------------------- |
| `구글상위노출` / `구글 상위노출` | 0회 / 33회 | 5,460 / 5,166 (둘 다 유효) |
| `구글SEO` / `구글 SEO`           | 8회 / 0회  | — / 1,000                  |
| `백링크업체` / `백링크 업체`     | 0회 / 2회  | 6,538 / 6,146              |
| `백링크작업` / `백링크 작업`     | 0회 / 5회  | 6,538 / 6,146              |

각 쌍에서 한쪽만 쓰고 있습니다. `[내부-Ads]` 기준으로는 **붙여쓰기 버전의 검색량이 오히려 더 높습니다**(6,538 > 6,146). 붙여쓰기 변형이 본문에 0회인 것은 손실입니다.

### `<br>` 단어 병합 문제 `[실측]`

렌더링된 HTML에서 텍스트를 추출하면 실제로 이렇게 나옵니다.

```
구글SEO와 구글 상위노출을 위한고품질 PBN 백링크와맞춤형 검색엔진최적화 솔루션
                              ^^^^^^^^            ^^^^^^^^^
```

같은 문제가 H2에도 있습니다.

```
95%의 백링크 업체는저품질 스팸 링크를 판매합니다
10가지 이상 고품질 백링크 유형으로자연스러운 검색엔진최적화
```

Google이 `<br>`을 공백으로 처리할 가능성이 높지만, 보장되지 않습니다. `<br>` 대신 CSS(`display:block` 또는 `<span class="block">`)로 줄바꿈하거나 `<br>` 앞뒤에 공백을 넣는 것이 안전합니다. **우선순위는 Low이지만 수정 비용이 거의 0입니다.**

H3 41개는 대부분 카드/리스트 항목입니다. 백링크 유형 12종, FAQ 6개, 상품 3종 등이 전부 H3으로 마크업되어 있습니다. 헤딩 계층 자체는 H1→H2→H3으로 건너뜀 없이 정상입니다 ✅.

## 3-7. 프롬프트 지정 분석 항목별 답변

### Q. Title이 현재 어떤 검색 의도를 타깃하는지

**특정 불가.** 정보성(구글SEO, 검색엔진최적화)과 상업성(고품질 백링크, 구글 상위노출) 키워드를 나열만 하고, 구매 의도 신호(구매·가격·업체)는 없습니다. 검색 의도를 타깃했다기보다 **키워드를 담은 것**에 가깝습니다.

### Q. H1이 어떤 키워드를 타깃하는지

구글SEO + 구글 상위노출 + 고품질 PBN 백링크 + 검색엔진최적화 — 4개 동시. Title과 거의 동일한 키워드 세트를 반복합니다. H1이 Title을 보완하지 못하고 중복합니다.

### Q. H2/H3 주제 분포

3-6 참조. 9개 H2가 4개 의도에 걸쳐 있고, 그 중 4개는 기존 별도 페이지와 중복.

### Q. 한 페이지에서 너무 많은 검색 의도를 동시에 공략하고 있는지

**예. 명확히 그렇습니다.** 최소 4개 의도(정보 탐색 / 업체 비교 / 구매 / 서비스 이해)를 한 페이지가 담당합니다. 이는 홈페이지의 욕심이라기보다 **다른 페이지가 전부 색인 불가라서 홈페이지가 떠맡을 수밖에 없는 구조적 결과**입니다.

### Q. 키워드 중복 및 과도한 반복 여부

**예.** "백링크" 121회 / 본문 대비 7.9%. H2 9개 전부에 "백링크" 포함. 3-2 참조.

### Q. 콘텐츠 주제의 일관성

⚠️ **부분적으로 일관됨.** 모든 섹션이 "백링크로 구글 상위노출"이라는 하나의 주장을 향하고 있어 주제 자체는 일관됩니다. 문제는 **각 섹션의 검색 의도 깊이가 다른데 한 페이지에 평면적으로 나열**된 점입니다.

### Q. 검색자 입장에서 페이지 목적이 명확한지

⚠️ **절반만.** "백링크를 파는 곳"이라는 것은 3초 안에 전달됩니다 ✅. 그러나 **"얼마인지"가 끝까지 불명확**합니다. 가격이 "300,000 크레딧~"으로만 표기되고, 크레딧과 원화의 환산율이 홈페이지 어디에도 없습니다 `[실측]`. 구매 결정에 필요한 정보가 로그인 뒤에 있습니다.

### Q. 구매 전환 UX와 SEO 콘텐츠가 자연스럽게 연결되는지

🔴 **연결이 끊겨 있습니다.** 홈페이지의 모든 상품 CTA("플랜 백링크 상품 보기", "PBN 백링크 상품 보기", "전체 SEO 백링크 상품 보기")가 `/products/*`를 가리키고, 이는 **비로그인 사용자에게 307 리다이렉트로 로그인 페이지**를 띄웁니다.

검색으로 들어온 방문자의 경로:

```
Google 검색 "백링크 구매"
   → 홈페이지 착지 (좋음, 1위 노출)
   → 6,101자 읽으며 설득됨
   → "PBN 백링크 상품 보기" 클릭
   → 307 리다이렉트
   → 로그인 페이지 (본문 55자, 가격 정보 0)
   → ❌ 이탈
```

가격을 확인하려는 자연스러운 행동이 **회원가입 요구**로 차단됩니다. 이것이 SEO 문제인 동시에 **전환율 문제**입니다.

## 3-8. 구조화 데이터 평가

`[실측]` JSON-LD 8블록, `@type`: `FAQPage`, `Organization`, `WebSite`, `Service`, `OfferCatalog`, `Offer`, `ContactPoint`, `SearchAction`, `Question`, `Answer`, `Country`

| 스키마                       | 상태          | 평가                                                                                                         |
| ---------------------------- | ------------- | ------------------------------------------------------------------------------------------------------------ |
| `FAQPage`                    | ✅ 6개 Q&A    | 본문 FAQ와 내용 일치 확인 ✅. 단 `/faq`에도 중복 존재                                                        |
| `Organization`               | ✅            | name/url/logo/contactPoint 포함. ⚠️ `address`, `sameAs`(SNS), 사업자정보 없음                                |
| `WebSite`                    | ✅            | `SearchAction`의 target이 `/products?q=` — 🔴 **해당 검색 기능이 실제로 없고, 그 URL은 로그인 리다이렉트됨** |
| `Service` + `OfferCatalog`   | ✅ 4개 서비스 | ⚠️ `Offer`에 **가격(`price`/`priceCurrency`)이 없음**                                                        |
| `Product`                    | ❌ 없음       | 🔴 상품 페이지가 차단되어 있어 붙일 곳이 없음                                                                |
| `BreadcrumbList`             | ❌ 없음       | 🔴 사이트 계층이 1단계뿐이라 현재는 붙일 계층도 없음                                                         |
| `AggregateRating` / `Review` | ❌ 없음       | 🔴 "98% 재구매율", 고객 후기 3건이 본문에 있으나 스키마화 안 됨                                              |

**즉시 고칠 것 2가지**

1. `WebSite.potentialAction.SearchAction.target`이 존재하지 않는 검색 기능을 가리킵니다. 사이트 내 검색이 없다면 `potentialAction` 자체를 제거해야 합니다. `[소스]` `app/components/StructuredData.tsx`
2. `Offer`에 가격이 없어 리치 결과에서 가격 표시를 못 받습니다.
