## B-2. 크롤러가 실제로 볼 수 있는 링크 그래프

`[실측]` 홈페이지 HTML에서 추출한 고유 내부 링크 경로는 **7개뿐**이며, 그 중 `/` 자기 링크를 빼면 6개, 그 6개 중 5개가 로그인 리다이렉트입니다.

```
                    ┌─────────────────────────────┐
   Googlebot ─────▶ │  /  (유일한 실질 색인 페이지)  │
                    └──────────────┬──────────────┘
                                   │ 내부링크 19개 (고유 경로 6개)
                    ┌──────────────┼───────────────────────────┐
                    ▼              ▼                           ▼
        /products (307)   /products/category/* (307×4)     /login (200)
                    │              │                           │
                    └──────────────┴──────────▶ /login ◀───────┘
                                                  │
                                       robots: index,follow
                                       title  : 홈페이지와 동일
                                       본문   : 55자
                                       링크   : 0개  ← 그래프 종료

        ╔══════════════════════════════════════════════════════╗
        ║  /services  /pricing  /faq  /cases                   ║
        ║  → 홈에서 링크 없음 · 사이트맵 없음 · canonical 홈 지정  ║
        ║  → 크롤러가 도달할 경로가 존재하지 않음 (완전 고아)      ║
        ╚══════════════════════════════════════════════════════╝
```

**결론**: 크롤러 관점에서 이 사이트는 **홈페이지 1개 + 막다른 로그인 페이지 1개**입니다. 나머지는 전부 도달 불가이거나 리다이렉트입니다.

## B-3. 페이지 역할 분류

프롬프트에서 지정한 8개 분류 기준에 따라 분류했습니다.

| 역할                   | 해당 URL                                                              | 개수  | 평가                                                  |
| ---------------------- | --------------------------------------------------------------------- | ----- | ----------------------------------------------------- |
| **홈**                 | `/`                                                                   | 1     | 🔴 홈 하나가 SEO랜딩·서비스·사례·FAQ 역할을 전부 겸함 |
| **SEO 랜딩페이지**     | —                                                                     | **0** | 🔴 **색인 가능한 전용 SEO 랜딩페이지가 하나도 없음**  |
| **서비스 페이지**      | `/services`                                                           | 1     | 🟡 존재하나 고아 + canonical 홈 지정                  |
| **상품 페이지**        | `/products`, `/products/category/*` (6), `/products/[id]`, `/pricing` | 9     | 🔴 8개는 로그인 차단, `/pricing`은 canonical 홈 지정  |
| **로그인/회원 페이지** | `/login`, `/dashboard`, `/credits`, `/orders`, `/admin/*`             | 다수  | ⚠️ `/login`만 색인 허용 (수정 필요)                   |
| **콘텐츠 페이지**      | `/faq`, `/cases`                                                      | 2     | 🟡 고아 + 홈과 내용 중복                              |
| **도구 페이지**        | `/analyze/[domain]`, `/email-preview`                                 | 2     | ⚫/🔴 전자는 의도적 noindex, 후자는 노출 사고         |
| **정책 페이지**        | —                                                                     | **0** | 🔴 **이용약관·개인정보처리방침·환불정책 전부 미존재** |

### 분류에서 드러나는 구조적 결함

1. **SEO 랜딩페이지 0개.** 광고용 LP는 7개나 만들어 두고 전부 `noindex` 처리했습니다. 광고 트래픽 전략으로는 타당하지만, **자연검색으로 유입될 착지점이 홈페이지밖에 없다**는 뜻입니다.
2. **정책 페이지 0개.** 상거래 사이트의 기본 신뢰 자산이 전무합니다.
3. **상품 페이지가 전부 로그인 뒤에 있음.** 상업 검색 의도(`PBN 백링크 가격`, `백링크 구매`)를 받아낼 페이지가 검색엔진에 존재하지 않습니다.

## B-4. 🔴 상품/서비스 페이지의 로그인 리다이렉트 — SEO 영향 상세

프롬프트에서 "특히 상품 또는 서비스 페이지가 로그인 페이지로 Redirect되는 경우 SEO에 어떤 영향을 주는지 명확히 기록하세요"라고 지정했으므로 별도로 정리합니다.

### 원인

`[소스]` `middleware.ts:87-93`

```ts
const protectedPaths = ['/dashboard', '/credits', '/products', '/orders', '/admin']
const isProtectedPath = protectedPaths.some(path => request.nextUrl.pathname.startsWith(path))

if (!user && isProtectedPath) {
  return NextResponse.redirect(new URL('/login', request.url))
}
```

`/products`가 보호 경로에 포함되어, 세션 쿠키가 없는 모든 요청 — 즉 **모든 검색엔진 크롤러** — 이 `/login`으로 307 리다이렉트됩니다. 미들웨어는 페이지 렌더링 이전 단계에서 실행되므로 크롤러는 상품 콘텐츠를 **단 한 글자도** 받지 못합니다.

### 구체적 SEO 영향

| #   | 영향                        | 설명                                                                                                                                                 |
| --- | --------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | **색인 불가**               | 5개 사이트맵 URL이 전부 색인되지 않음. GSC 색인 범위 보고서에서 "페이지에 리디렉션이 있음"으로 제외 처리됨                                           |
| 2   | **사이트맵 신뢰도 하락**    | 사이트맵의 83%(6개 중 5개)가 리다이렉트 URL. Google은 사이트맵 품질이 낮으면 크롤 우선순위를 낮춤                                                    |
| 3   | **상업 키워드 착지점 상실** | `PBN 백링크 가격`, `백링크 구매 사이트` 등 구매 직전 의도의 키워드를 받을 페이지가 없음. 홈페이지가 대신 받으면 검색의도-페이지 불일치로 이탈률 상승 |
| 4   | **내부 링크 자산 소실**     | 홈페이지 내부링크 19개 중 대부분이 리다이렉트 URL을 향함. PageRank가 최종적으로 **본문 55자짜리 `/login`으로 집중**되는 최악의 링크 그래프           |
| 5   | **크롤 예산 낭비**          | `/products/category/{임의문자열}`이 404가 아닌 307을 반환 → 무한 URL 공간이 전부 리다이렉트                                                          |
| 6   | **구조화 데이터 기회 상실** | 상품 페이지에 `Product`/`Offer`/`AggregateRating` 스키마를 붙이면 리치 결과(가격·평점 표시)를 노릴 수 있으나 페이지 자체가 노출되지 않음             |
| 7   | **유료 광고 손실 동반**     | Google Ads 사이트링크 "백링크 상품 전체 보기"가 `/products`를 가리킴 → **광고 클릭이 로그인 벽에 착지** (07·10번 문서 참조)                          |

### 정상적인 설계와의 비교

경쟁사 `linkauthority.kr`은 서비스 상세 페이지 9개를 **전부 공개**하고 있습니다 `[실측]`.

```
linkauthority.kr/services/pbn-backlinks       ← 공개 · 색인
linkauthority.kr/services/tier-links          ← 공개 · 색인
linkauthority.kr/services/onpage-seo          ← 공개 · 색인
...
```

상거래 사이트의 표준 패턴은 **상품 정보는 공개, 결제/주문만 인증**입니다. 현재 구조는 "가격표를 보려면 회원가입부터 하세요"에 해당하며, SEO뿐 아니라 전환율 관점에서도 불리합니다.

### 권장 수정 방향

`middleware.ts`의 `protectedPaths`에서 `/products`를 제거하고, 구매 액션(장바구니 담기·결제 서버 액션)에서만 인증을 확인하는 방식으로 전환. 상세는 [13-recommendations.md](13-recommendations.md).

### 이 표에서 읽어야 할 것

**타깃 키워드를 배정받은 페이지 수 = 1개(홈페이지).** 나머지는 전부 키워드를 배정받았어도 착지가 불가능합니다.

홈페이지 하나가 최소 **4개의 서로 다른 검색 의도**를 동시에 공략하고 있습니다.

| 검색 의도                            | 대표 키워드                          | 적정 페이지 유형 | 현재                         |
| ------------------------------------ | ------------------------------------ | ---------------- | ---------------------------- |
| 정보 탐색 (Informational)            | 백링크, 백링크 뜻, 백링크 효과       | 가이드/블로그 글 | 홈                           |
| 업체 비교 (Commercial Investigation) | 백링크 업체, SEO 대행사, 백링크 가격 | 비교/가격 랜딩   | 홈                           |
| 구매 (Transactional)                 | 백링크 구매, PBN 백링크 구매         | 상품 페이지      | 홈 (실제 상품 페이지는 차단) |
| 서비스 이해                          | 구글SEO, 검색엔진최적화              | 서비스 페이지    | 홈                           |

이 4개를 한 페이지에 몰아넣은 결과가 [03-homepage-seo-analysis.md](03-homepage-seo-analysis.md)에서 측정한 **"백링크" 121회 반복 / 본문 대비 7.9%** 라는 과최적화 수치입니다.
