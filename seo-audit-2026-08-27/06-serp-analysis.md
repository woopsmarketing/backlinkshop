# F. 핵심 키워드 SERP 분석 · SERP Overlap

**조사일: 2026-08-27** · 출처: `[DDG-KR]` DuckDuckGo HTML 엔드포인트 (`kl=kr-kr`, `Accept-Language: ko-KR`)

---

## ⚠️ 데이터 출처 한계 — 반드시 먼저 읽어주세요

프롬프트는 **"한국 Google"** SERP 조사를 요구했습니다. **한국 Google SERP는 확보하지 못했습니다.**

Google 검색 결과 페이지에 서버 요청을 보낸 결과, JavaScript 실행이 필수인 셸 페이지만 반환되었습니다 `[실측]`.

```
<noscript><meta content="0;url=/httpservice/retry/enablejs?..." http-equiv="refresh">
```

결과 링크가 HTML에 포함되지 않아 파싱이 불가능했습니다.

**대체 수단으로 DuckDuckGo의 한국 지역 설정(`kl=kr-kr`) 결과를 사용했습니다.**

| 항목                        | 내용                                                                                         |
| --------------------------- | -------------------------------------------------------------------------------------------- |
| DuckDuckGo의 인덱스 출처    | **Microsoft Bing**                                                                           |
| Google과 같은가?            | ❌ **아니오** — 알고리즘·인덱스가 다름                                                       |
| 그래도 유용한 이유          | 한국어 SEO 시장의 **경쟁 구도, 페이지 유형 분포, 콘텐츠 전략**은 두 엔진에서 유사하게 나타남 |
| 이 데이터로 하면 안 되는 것 | **"Google에서 몇 위다"라고 단정하기**                                                        |
| 이 데이터로 해도 되는 것    | 경쟁사 식별, 검색 의도 판정, 페이지 유형 분석, SERP Overlap 판단                             |

**본 문서의 모든 "순위"는 `[DDG-KR]` 기준이며, Google 순위가 아닙니다.** Google 실순위는 Search Console 또는 Ahrefs/Semrush 순위추적으로 확보해야 합니다 → [09-search-console.md](09-search-console.md)

## F-4. SERP 분석 핵심 요약

1. **backlinkshop은 3개 키워드에서 1위입니다** — `백링크 구매`, `고품질 백링크`, `PBN 백링크`. 콘텐츠 경쟁력은 이미 증명되었습니다.
2. **놓치고 있는 4개** — `백링크`, `백링크 업체`, `백링크 가격`, `링크빌딩`. 전부 **전용 페이지가 없어서** 놓치고 있습니다.
3. **`백링크 가격`이 가장 아깝습니다** — `/pricing` 페이지가 실재하는데 canonical 오류로 무력화.
4. **경쟁사의 무기는 블로그입니다** — `rankrocket.kr` 글 1편이 4개 SERP를 동시 점유. backlinkshop은 블로그 0개.
5. **`링크빌딩`·`구글 SEO`는 지금 구조로는 불가능** — SERP가 위키백과/Google 공식문서/대기업 블로그로 채워져 있어, 서비스 페이지가 아니라 **콘텐츠 또는 무료 도구**로만 진입 가능.
