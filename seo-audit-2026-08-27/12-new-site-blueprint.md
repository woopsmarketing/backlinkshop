## K. 새 사이트에서 필요할 것으로 예상되는 Landing Page 목록

### K-1. 설계 근거

각 페이지는 다음 4가지 중 최소 2개를 근거로 제안했습니다.

1. `[DDG-KR]` SERP Overlap 분석 — 별도 페이지가 필요한 키워드군 ([06](06-serp-analysis.md) F-3)
2. `[자동완성]` Google 한국어 자동완성에서 확인된 실제 질의
3. `[실측]` 경쟁사가 해당 페이지를 보유하고 상위 노출 중
4. `[소스]` **이미 콘텐츠 자산이 존재**하여 재배치만 하면 되는 경우

## L. 새 Blog / Content Cluster 후보

### L-1. 왜 블로그가 최우선인가

`[실측]` 경쟁사 대비 가장 큰 격차입니다.

| 사이트                 |         블로그 콘텐츠 수 |
| ---------------------- | -----------------------: |
| linkauthority.kr       |              **약 64편** |
| rankrocket.kr          | 다수 (정확 수 확인 불가) |
| subbot.kr              |                      7편 |
| backlinkpro.kr         |                     보유 |
| **backlinkshop.co.kr** |  **0편** (`/blog` → 404) |

그리고 **경쟁사 상위 노출의 실체가 블로그 글**입니다 `[DDG-KR]`.

`rankrocket.kr/blog/complete-backlink-guide-2026` **한 편**이 잡고 있는 SERP:

| 키워드      |  순위   |
| ----------- | :-----: |
| 백링크      |  10위   |
| 백링크 구매 | **3위** |
| 백링크 판매 | **2위** |
| 백링크 가격 | **2위** |

**블로그 글 1편 = 상업 키워드 4개 SERP 동시 진입.** 서비스 페이지로는 불가능한 일입니다.

## L-10. 블로그 운영 시 기술 요건
