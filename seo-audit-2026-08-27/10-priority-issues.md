## H-5. 우선순위 실행 순서 (권장)

### 1단계 — 즉시 (코드 수정만, 1~2일)

```
C1  canonical 수정          → 색인 가능 페이지 1개 → 5개
C3  robots.txt 신설
C4  sitemap.ts 재작성
H4  /login noindex
H5  /email-preview noindex
H7  수치 불일치 4종 수정
M4  SearchAction 제거
```

> **이 7건은 전부 파일 5~6개 수정으로 끝납니다.** 신규 콘텐츠 작성이 필요 없고, 리뉴얼 여부와 무관하게 지금 해도 손해가 없습니다. **투입 대비 효과가 가장 큰 구간입니다.**

### 2단계 — 단기 (1~2주)

```
C2  /products 로그인 차단 해제  → 상품 페이지 색인 개시 (H3도 동시 해소)
H1  정책 페이지 3종 신설
H2  /signup 404 해결          → 광고 예산 누수 차단
M3  크레딧 원화 환산 공개
```

### 3단계 — 리뉴얼 본작업

```
C5  의도별 랜딩 페이지 신설      → 12번 문서
H6  키워드 재배분
M1  홈페이지 카피 재작성
M8  FAQ 중복 해소
    블로그 신설 (경쟁사 대비 최대 격차)
```

### 4단계 — 정리

```
M2, M5, M6, M7, M9, L1~L7
```
