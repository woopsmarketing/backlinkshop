### I-1. 🥇 1위 확보 키워드 3개 — 최우선 보존 자산

| 키워드            |  순위   | Ranking URL                           | `[내부-Ads]` CPC |
| ----------------- | :-----: | ------------------------------------- | ---------------: |
| **백링크 구매**   | **1위** | `https://www.backlinkshop.co.kr` (홈) |          9,446원 |

**세 키워드 모두 홈페이지 URL(`/`)이 잡고 있습니다.**

> ⚠️ **보존 규칙**: 홈페이지 URL(`/`)은 **절대 변경하지 마세요.** 그리고 홈페이지에서 `백링크 구매`·`고품질 백링크`·`PBN 백링크` 3개 키워드를 **title 또는 H1에서 제거하지 마세요.** 리뉴얼로 홈 카피를 재작성할 때 이 3개는 반드시 남겨야 합니다.
>
> 특히 주의: 이 3개를 신규 하위 페이지(`/services/pbn` 등)로 **완전히 이관**하면 홈페이지가 갖고 있던 순위를 잃고 신규 페이지가 그 자리를 못 받을 위험이 있습니다. **홈에 남기고 하위 페이지는 롱테일(`PBN 백링크 가격`, `PBN이란`)로 분화**시키는 것이 안전합니다.

`www` 정본 설정과 http→https, 슬래시 정규화도 이미 올바릅니다 `[실측]`. **유지.**

## J. 리뉴얼 시 반드시 Redirect해야 할 기존 URL

### J-1. 원칙

| 규칙      | 내용                                                                                              |
| --------- | ------------------------------------------------------------------------------------------------- |
| 상태코드  | **301 (영구)** 사용. 307/302 금지                                                                 |
| 매핑      | 1:1 매핑 우선. 대응 페이지가 없으면 **가장 가까운 상위 페이지**로 (홈 일괄 리다이렉트는 최후수단) |
| 체인 금지 | A→B→C 금지. 항상 A→C 직접                                                                         |
| 유지 기간 | 최소 **12개월**                                                                                   |
| 검증      | 배포 직후 전 URL 상태코드 재확인 + GSC 색인 범위 모니터링                                         |

### J-2. 🔴 최우선 — 절대 변경 금지 URL

| URL              | 사유                                       | 조치                                                              |
| ---------------- | ------------------------------------------ | ----------------------------------------------------------------- |
| **`/`**          | **1위 키워드 3개를 잡고 있는 유일한 자산** | **URL 유지. 리다이렉트 대상 아님.** 카피 재작성 시에도 URL은 고정 |
| `/sitemap.xml`   | 크롤러 진입점                              | 유지 (내용만 갱신)                                                |
| `/auth/callback` | OAuth 콜백 — 변경 시 로그인 파손           | 유지                                                              |

### J-3. 리다이렉트 매핑표

#### 그룹 A — 현재 색인 가능 페이지 (URL 유지 권장)

이 4개는 **URL을 바꾸지 말고 canonical만 고치는 것**을 권장합니다. 이미 존재하는 URL이고 Google Ads 사이트링크가 물려 있습니다 `[내부-Ads]`.

| 기존 URL    | 권장     | 사유                                                                        |
| ----------- | -------- | --------------------------------------------------------------------------- |
| `/services` | **유지** | Ads 사이트링크 연결 없음이나 서비스 허브로 계속 사용                        |
| `/pricing`  | **유지** | ⚠️ **Ads 사이트링크 "요금제 · 크레딧 패키지"가 연결됨** — 변경 시 광고 파손 |
| `/cases`    | **유지** | ⚠️ **Ads 사이트링크 "성공 사례 · 실제 순위"가 연결됨**                      |
| `/faq`      | **유지** | ⚠️ **Ads 사이트링크 "자주 묻는 질문 (FAQ)"이 연결됨**                       |

> 🔴 **경고**: 이 4개 URL을 바꾸면 **Google Ads 사이트링크 3개가 동시에 깨집니다.** 변경이 불가피하다면 광고 애셋의 final_url을 **같은 배포에서 함께 수정**해야 합니다.

| `/products/category/content` |  ✅ 0.7  | `/services/content-seo`                  | **301**                 |

### J-4. Google Ads 자산과 URL 의존성 — 리뉴얼 전 필독

`[내부-Ads]` 리뉴얼로 URL이 바뀌면 **함께 수정하지 않으면 광고가 깨지는** 항목입니다.

| ----------------------------------- | ----------------------- | ---------------- | ----------------------- |
| 사이트링크 "무료 SEO 진단 시작"     | `/lp/seo?ref=audit`     | ✅ 200           | LP URL 유지 필요        |
| 사이트링크 "백링크 상품 전체 보기"  | `/products`             | 🔴 **307→login** | C2 해결 시 정상화       |

| 사이트링크 "자주 묻는 질문 (FAQ)"   | `/faq`                  | ✅ 200           | URL 유지 필요           |

### J-5. 리뉴얼 전 반드시 백업할 것

|   # | 항목                                         | 사유                                                                       |

|   4 | Google Ads 애셋 전체 (final_url 포함)        | J-4 대조용                                                                 |
|   5 | 현재 순위 스냅샷                             | 리뉴얼 전후 비교 기준선                                                    |

> ⚠️ **1번이 특히 중요합니다.** GSC 데이터 없이는 "트래픽이 있었지만 이 조사에서 발견하지 못한 URL"이 있는지 알 수 없습니다. 본 조사는 소스코드 라우트 전수 + 홈페이지 링크 추적으로 URL을 수집했으므로, **외부에서만 링크된 URL이나 과거에 존재했다 사라진 URL은 포착하지 못했을 수 있습니다.**

### J-6. 배포 후 검증 체크리스트

|   # | 확인                                                      | 방법                    |
| --: | --------------------------------------------------------- | ----------------------- |
|   1 | 전 리다이렉트가 **301**인가 (302/307 아님)                | `curl -I` 전수 확인     |
|   2 | 리다이렉트 체인이 없는가                                  | 최종 URL까지 홉 수 확인 |
|   3 | 신규 sitemap.xml의 **모든 URL이 200**인가                 | 전수 확인               |
|   4 | 전 페이지 canonical이 **자기참조**인가                    | 전수 확인               |
|   5 | `robots.txt`가 200이고 Sitemap 지시문 포함                | 확인                    |
|   6 | `/login` `/email-preview` `/lp/*`가 **noindex**인가       | 확인                    |
|   7 | Google Ads 전 애셋 final_url이 **200**인가                | J-4 표 전수             |
|   8 | GSC에 신규 sitemap 재제출                                 | GSC                     |
|   9 | GSC 색인 범위 보고서 2~4주 모니터링                       | GSC                     |
|  10 | `백링크 구매`·`고품질 백링크`·`PBN 백링크` 순위 유지 확인 | 순위추적                |

> **10번이 가장 중요합니다.** 이 3개 키워드의 1위는 현재 사이트의 유일한 SEO 성과입니다. 리뉴얼 후 2~4주간 주간 단위로 확인하고, 하락 시 홈페이지 카피 변경분을 즉시 되돌릴 수 있도록 준비하세요.
